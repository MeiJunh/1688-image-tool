# 测试报告 — 1688 商品图下载 + 自动去水印

- 测试日期：2026-07-04
- 测试环境：macOS（开发机），Python 3.9.6，opencv-python 5.0.0，numpy 2.0.2，requests
- 去水印引擎：opencv（`cv2.inpaint`）。iopaint 引擎为可选增强，逻辑同路径，本次未在测试机安装。
- 结论：**5 / 5 全部通过**。核心链路（自动检测水印 → 去水印 → 带 Referer 下载 → 服务全链路）均验证有效。

> 说明：受条件限制，测试用**合成图**（多张不同背景叠加同一固定位置半透明水印，模拟 1688 同一商品的多图场景），
> 而非直接抓取真实 1688 页面（涉及登录/风控，且真实抓取由浏览器油猴脚本完成，见"未覆盖项"）。

## 一、测试方法

`tests/make_fixtures.py` 生成 6 张 600×600 图：
- 每张有**不同的随机背景**（渐变 + 随机色块/圆 + 噪声），模拟不同商品图；
- 叠加**同一位置、同一样式**的半透明水印（底部 `SHOP-1688-OFFICIAL` + 右上角 `WM`，透明度 0.42）；
- 同时保存无水印真值 `gt/` 与水印真实位置 `truth/`，用于量化评估。

`tests/test_pipeline.py` 跑 4 类共 5 个用例，结果写入 `tests/test_result.json`。

## 二、用例与结果

| 编号 | 用例 | 结果 | 指标 |
|---|---|---|---|
| A | 自动检测水印 · 召回率 | ✅ PASS | 平均召回 **98.4%**（阈值 ≥75%） |
| B | 去水印 · 水印区误差下降 | ✅ PASS | 误差 27.3 → 7.7，**下降 72%**（阈值 ≥40%） |
| C | 带 Referer 下载全部图 | ✅ PASS | 下载 **6/6**，失败 0 |
| D1 | 服务健康检查 `/health` | ✅ PASS | 返回 `{ok:true}` |
| D2 | 全链路产物落地 | ✅ PASS | `clean/` 下 6 张，目录含非法字符已安全处理 |

### A. 自动检测水印（召回率 98.4%）
跨图一致性算法生成的蒙版，覆盖了 98.4% 的真实水印像素。含义：水印被稳定、完整地定位出来。

### B. 去水印效果（水印区误差下降 72%）
以无水印真值为基准，只统计水印覆盖区域：
- 去水印**前**平均像素误差：27.3
- 去水印**后**：7.7
- 下降 **72%**，说明水印被有效抹除、并用周边像素合理填补。

### C. 下载模块（6/6）
用本地静态服务器充当图片站，服务端带 `Referer` / `User-Agent` 头并发下载，6 张全部成功落盘，
文件按 `序号_哈希.ext` 命名（保序、可追溯）。验证了下载头、并发、命名、过小文件过滤逻辑。

### D. 服务全链路（健康检查 + 产物落地）
启动 `server.py`，`/health` 正常；`POST /process` 传入含非法字符的商品名与 6 个图片链接，
服务完成"下载 → 自动去水印 → 落盘"，`clean/` 下产出 6 张成品，商品名中的 `/ *` 等非法字符被安全替换。

## 三、可视化验证

`tests/compare.png`（三联图：原图 / 自动蒙版 / 去水印后）人工核对确认：
- 蒙版**精准命中水印文字**，未误框商品内容（色块、圆形边缘均未进入蒙版）；
- 成品图水印文字消失，商品主体完整保留。

> 算法迭代记录：初版用"平均边缘强度取百分位"，会把高对比内容边缘误框；
> 改为"强边缘在≥80%的图中同位置出现才判为水印"后，误框基本消除，召回仍达 98.4%。

## 四、未覆盖项 / 已知限制

1. **未对真实 1688 页面做端到端联调**：真实抓图由浏览器里的油猴脚本完成，依赖登录态与页面结构，
   需你在 Windows + Chrome 实机上验证。油猴脚本已通过 `node --check` 语法校验，逻辑经人工审阅。
2. **iopaint 引擎未在本机实测**：仅测了 opencv 引擎。iopaint 走相同的"蒙版→修复"接口，
   装好后按同路径调用；建议你在 Windows 上装 iopaint 后用真实图对比两种引擎效果。
3. **合成水印 vs 真实水印**：真实 1688 水印字体/透明度/是否平铺各异。跨图一致性对
   "位置固定、多图一致"的水印最有效；若某店水印**每张位置都不同**或**只有单张图**，
   自动检测会变弱，此时建议用 `config.json` 的 `regions` 为该店配固定区域模板（最准）。
4. **过度/不足去除的调参**：真实场景可能需要微调 `edge_percentile`（强边缘分位）与 `dilate`（膨胀）。
   每次运行会在 `clean/_masks/` 保存蒙版，据此调参最直观。
