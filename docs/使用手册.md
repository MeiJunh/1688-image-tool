# 使用手册 — 1688 商品图下载 + 自动去水印

面向 Windows。整套东西分两块：**电脑上跑的本地服务** + **浏览器里的一个按钮**。装一次，以后每次用只需"开着服务 → 页面点按钮"。

---

## 一、第一次安装（约 10 分钟，只做一次）

### 1. 安装 Python
1. 打开 https://www.python.org/downloads/ ，下载 Windows 版 Python 3.10 或更新版本。
2. 运行安装包，**第一屏一定勾选 “Add Python to PATH”**，再点 Install。

### 2. 安装本地服务依赖
1. 把本项目文件夹放到电脑上，比如 `D:\1688-tool`。
2. 在该文件夹地址栏输入 `cmd` 回车，打开命令行窗口，依次执行：
   ```bat
   cd server
   pip install -r requirements.txt
   ```
   等它装完（联网下载，几分钟）。

> 想要**更好的去水印效果**（可选）：再执行 `pip install iopaint`，然后把 `server/config.json`
> 里的 `"engine": "auto"` 保持不变即可，程序会自动优先用它。第一次运行会下载模型，需等待。

### 3. 安装浏览器脚本
1. Chrome 或 Edge 应用商店搜索安装 **Tampermonkey（油猴）** 扩展。
2. 点浏览器右上角油猴图标 → **添加新脚本**。
3. 把 `userscript/1688-grab.user.js` 文件用记事本打开，**全选复制**，粘贴替换掉编辑器里的内容。
4. `Ctrl+S` 保存。完成。

## 二、每次使用（三步）

### 第 1 步：启动本地服务
在 `server` 文件夹地址栏输入 `cmd` 回车，执行：
```bat
python server.py
```
看到下面这样就成功了，**这个黑窗口不要关**，用的时候一直开着：
```
  1688 图片下载 + 自动去水印  本地服务已启动
  监听: http://127.0.0.1:8788
```

### 第 2 步：打开 1688 商品页，点按钮
1. 浏览器打开任意一个 1688 商品详情页。
2. 页面**右下角**会出现橙色按钮 **“⬇ 下载+去水印”**，点它。
3. 按钮会依次显示进度：`正在加载全部图片…` →（自动滚动加载详情图）→ `已开始后台处理` → `下载中 x/N` → `去水印中 x/N` → `✅ 完成 X/Y`。

> **后台处理**：点按钮后任务在电脑后台跑，**浏览器不会一直卡住**，你可以继续浏览别的页面，
> 按钮会自己轮询更新进度。用 CPU 跑 iopaint 时"去水印中"可能持续几分钟到十几分钟，属正常，耐心等或看黑窗口进度。

### 第 3 步：取图
处理好的图在项目的 `output` 文件夹里，按"商品名_时间"分好文件夹：
```
output/
  连衣裙夏款_20260704_143012/
    original/   ← 下载的原图
    clean/      ← 去水印后的成品（用这个）
      _masks/   ← 自动识别的水印区域（一般不用管，调参时看）
```

## 三、常见问题

**按钮点了显示"连不上本地服务"**
→ 第 1 步的黑窗口没开，或被关了。重新 `python server.py`。
（注意：v1.2 起改为后台异步处理，长任务不会再因为等太久而报"连不上"；真报这个就是服务没启动。）

**按钮显示"未找到图片"**
→ 可能页面还没加载完，或不是商品详情页。刷新页面、等图片显示出来再点。

**图片下载失败几张**
→ 个别链接失效或防盗链，属正常。`output/.../original` 里能看到成功的。失败详情在黑窗口日志里。

**黑窗口一直刷 `can't open/read file: check file path/integrity`，且水印没去除（显示"未检测到水印"）**
→ 这是旧版在 Windows 上遇到**中文路径**时 OpenCV 读不了图导致的。已在最新版修复。
请从仓库拉最新的 `server/` 代码（新增了 `server/imio.py`，并改用兼容中文路径的读写），重启 `server.py` 即可。

**水印没去干净 / 商品被误擦了一点**
→ 打开 `clean/_masks/` 看白色区域是不是准。然后调 `server/config.json`：
- 水印没框全 → 把 `dewatermark.consistency.dilate` 调大（如 6 → 9）。
- 误框了商品 → 把 `edge_percentile` 调大（如 85 → 90），或 `dilate` 调小。
- 改完**重启** `server.py` 生效。

**某家店水印每张位置都一样、想要最精准**
→ 用"固定区域模板"。在 `config.json` 的 `regions` 里按店铺域名加矩形（相对比例 0~1，`[左, 上, 右, 下]`）：
```json
"regions": {
  "detail.1688.com": [[0.0, 0.88, 1.0, 1.0]]
}
```
上例表示"抹掉每张图最底部 12% 的水印条"。配了它对该域名就用固定区域，最稳。

**想让去水印效果更好**
→ 安装 iopaint（见安装第 2 步的可选项）。它用 AI 模型修复，比默认引擎自然。

## 四、配置速查（server/config.json）

| 项 | 作用 | 建议 |
|---|---|---|
| `server.port` | 服务端口 | 默认 8788，一般不改 |
| `download.referer` | 下载用的来源头 | 默认即可 |
| `dewatermark.enabled` | 是否去水印 | `false` 则只下载不去水印 |
| `dewatermark.engine` | 引擎 | `auto`（有 iopaint 用它，否则 opencv）/ `opencv` / `iopaint` |
| `dewatermark.mask_strategy` | 找水印方式 | `consistency`（默认，多图自动）/ `region`（固定模板）/ `heuristic`（单图兜底） |
| `consistency.edge_percentile` | 强边缘分位 | 越大越保守（少框），默认 85 |
| `consistency.dilate` | 蒙版膨胀 | 越大框越粗，默认 6 |
| `regions` | 各店固定水印区 | 见上文 |

## 五、关于 iPad（后续可选）

当前方案是 Windows 本地免费版，iPad 用不了（iPad 装不了本地服务）。
若以后想让 iPad 也能用，需要把这个本地服务搬到一台云服务器上（有月成本），届时可再扩展。
